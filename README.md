# نظام الصيدلية (Pharmacy System)

برنامج ويندوز لإدارة الصيدلية، مبني بـ Electron وقاعدة بيانات SQLite محلية (تشتغل بدون إنترنت).

## المميزات
- **المبيعات (كاشير)**: قراءة الباركود من الماسح، بحث بالاسم العربي/الإنجليزي/المادة الفعالة، بيع علبة أو شريط، خصم على الصنف أو الفاتورة، كاش/فيزا/آجل/مختلط، تعليق الفواتير، طباعة إيصال 80mm.
- **البدائل (المثائل)**: أي صنف يظهر معه بدائله بنفس المادة الفعالة مع السعر والمتاح.
- **تنبيهات التفاعلات الدوائية** الشائعة داخل الفاتورة (للاستئناس، والمراجعة النهائية للصيدلي).
- **المخزون بالتشغيلات وتواريخ الصلاحية**: البيع تلقائياً بأقرب صلاحية (FEFO)، تنبيه قرب الانتهاء، الأصناف المنتهية، النواقص بحد طلب لكل صنف، جرد وتسوية.
- **المشتريات والموردين**: فواتير شراء بتشغيلات وصلاحيات وتحديث التكلفة وسعر البيع، مديونيات الموردين والسداد.
- **العملاء**: حسابات آجلة وتحصيل وكشف حساب وملاحظات الأمراض المزمنة.
- **المرتجعات** بالفاتورة مع إرجاع الكمية لنفس التشغيلة.
- **الوردية والمصروفات**: فتح/إقفال وردية وجرد الدرج مع الفرق.
- **التقارير**: مبيعات، أرباح، الأكثر مبيعاً، حسب الكاشير، يومي، مديونيات، قيمة المخزون، تصدير CSV.
- **مستخدمون وصلاحيات** (مدير/صيدلي/كاشير) برقم سري، **نسخ احتياطي تلقائي يومي** + حفظ واسترجاع يدوي.
- **قاعدة الأدوية المصرية**: أكثر من 27 ألف صنف (أدوية + مستحضرات تجميل وعناية) بالأسعار والشركات والمواد الفعالة وأكثر من 10 آلاف باركود. الصنف اللي مالوش باركود تقدر تربطه بأول مسح.

الدخول الافتراضي: **المدير** والرقم السري **1234** (البرنامج يطلب تغييره أول دخول).

## التشغيل والبناء
```bash
npm install
npm run build-db   # ينشئ قاعدة البيانات data/pharmacy.seed.db من db/schema.sql + كتالوج الأدوية
npm start          # تشغيل البرنامج
npm run dist       # بناء ملف التثبيت لويندوز (dist/)
```
البناء الآلي لملف التثبيت (`.exe`) يتم عبر GitHub Actions ويُنشر في صفحة Releases.

## هيكل المشروع
- `db/schema.sql` هيكل قاعدة البيانات (الجداول)
- `scripts/build-db.js` إنشاء قاعدة البيانات واستيراد كتالوج الأدوية
- `main.js` / `preload.js` عملية Electron والوصول لقاعدة البيانات (sql.js)
- `src/` واجهة البرنامج
